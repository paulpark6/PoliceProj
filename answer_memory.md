# Answer Memory (PoliceProj capstone script)

## Answers
- Answer the question directly. No extras, notes, alternatives, or justifications unless asked.
- Yes/no questions: start with "Yes." or "No.", then name what applies.
- Lists of variables: one variable per line.
- Every answer line starts with `#`.
- No semicolons in answers. Use separate sentences.
- Variable type = type - level (e.g., categorical - nominal, numeric - continuous/ratio).
- "What does it tell us?" = plain meaning first (e.g., "The average X is A and the middle X is B."), then the technical point.
- Check every answer against rules.md.

## Code
- Simplest base/tutorial code: read_csv(), View(), str(), table(df$x).
- One line per variable; no loops, lapply, or helpers.
- Run the script after each step to confirm it works.

## Chat replies
- Short. Use a table: Title | What it changes | Files/things affected | Status.
- End with one short verify question.
